# 名刺管理(meishi-tools)

iPhoneのSafariで動く、個人用の名刺管理PWA(Progressive Web App)です。

- カメラで名刺を撮影 → 自動で輪郭検出・矩形補正(手動での微調整も可能)
- Google Cloud Vision APIでOCRし、会社名・氏名・電話番号・メールアドレスを読み取り
- 会社名・氏名(五十音)でソート・検索
- あとから会社名・氏名・フリガナを編集可能
- 電話番号・メールアドレスがあれば `tel:` / `mailto:` でワンタップ発信・メール作成
- データはすべて自分のGoogle Drive上に保存(サーバーは使いません)

## 使う前に必要な設定(あなたご自身の作業)

このアプリはサーバーを持たない静的サイトのため、Google Cloud / GitHub の設定はコードからは自動化できません。以下を順番に行ってください。

### 1. Google Cloud Console

1. https://console.cloud.google.com/ でプロジェクトを新規作成(または既存のものを利用)
2. 「APIとサービス > ライブラリ」から **Cloud Vision API** と **Google Drive API** を有効化
3. 「APIとサービス > 認証情報」から **APIキー** を発行し、以下の制限を必ず設定する
   - アプリケーションの制限: **HTTPリファラー(ウェブサイト)** → `https://<あなたのGitHubユーザー名>.github.io/meishi-tools/*` を登録
   - API制限: **Cloud Vision API のみ** を許可
4. 「IAMと管理 > 割り当てとシステム上限」で Vision API の1日あたりのリクエスト数を100〜300程度に絞っておく(万一キーが漏れた場合の被害を限定するため)
5. 「お支払い > 予算とアラート」で月$5程度の予算アラートを設定しておく
6. 「APIとサービス > OAuth同意画面」を設定
   - User Type: External
   - テストユーザーに自分のGoogleアカウント(このアプリを使うアカウント)を追加
   - 公開ステータスは「テスト」のままで問題ありません(個人利用のため)
7. 「APIとサービス > 認証情報」から **OAuthクライアントID**(種類: ウェブアプリケーション)を発行
   - 承認済みのJavaScript生成元に `https://<あなたのGitHubユーザー名>.github.io` を登録(パスは不要)

> Vision APIキーはこのアプリの性質上、ブラウザ側のJavaScriptに埋め込まれます(静的サイトのためサーバー側に隠せません)。3〜5の制限を必ず設定し、「秘匿」ではなく「万一漏れても被害を限定する」という考え方で運用してください。OAuthクライアントIDはそもそも公開されて問題ない値です(クライアントシークレットは使用しません)。

### 2. `js/config.js` を編集する

リポジトリ内の `js/config.js` を開き、以下を書き換えてコミットしてください。

```js
window.MT_CONFIG = {
  VISION_API_KEY: "上で発行したAPIキー",
  GOOGLE_CLIENT_ID: "上で発行したOAuthクライアントID",
  ...
};
```

### 3. GitHubリポジトリの作成とGitHub Pages設定

1. GitHub上に新規リポジトリ `meishi-tools` を作成(Public推奨)
2. このフォルダの中身をpush
3. リポジトリの Settings > Pages で以下を設定
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)`
4. しばらくすると `https://<あなたのGitHubユーザー名>.github.io/meishi-tools/` でアクセスできるようになります

### 4. iPhoneでホーム画面に追加

1. iPhoneのSafariで上記URLを開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面のアイコンから起動するとアプリのような全画面表示になります

## 使い方

1. 初回起動時、「Googleでログイン」でご自身のGoogleアカウントにログイン(Drive内に「名刺管理アプリ」フォルダが自動作成されます)
2. 「スキャン」タブで名刺を撮影 → 四隅を確認・調整して確定 → OCR実行
3. 読み取った文字候補をタップして各欄に転記、または直接入力して登録
4. 「一覧」タブで五十音順・登録日順に並び替え、検索が可能
5. 一覧から名刺をタップすると詳細・編集・削除、電話/メールのワンタップ発信ができます

## 既知の制約

- ログインのトークンは約1時間で失効します。失効後は再度「ログイン」ボタンをタップしてください(自動更新はSafariのプライバシー制限により行いません)
- 名刺データのオフライン編集には対応していません(閲覧の一部はキャッシュされますが、スキャン登録・保存にはネットワーク接続が必要です)
- 会社名・氏名の自動判定は行わず、OCR結果の候補から手動で割り当てる方式です(誤読による誤登録を防ぐため)
- フリガナは自動変換されません。手動で入力してください
